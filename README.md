## 場館與資料

- 原本 6 個場館、原本小巨蛋 `rentals.json` 37 筆、原本其他 5 個場館 `events.json` 32 筆均保留。
- 新增 6 個場館：臺北大巨蛋、女巫店、The Wall Live House、河岸留言西門紅樓展演館、PIPE Live Music、台北國際會議中心 TICC。
- 新增活動為已找到來源的部分公告，不代表完整檔期。每筆資料都帶 `source_url`；如為場館總節目頁，該連結不代表逐筆獨立公告。
- 大巨蛋部分場次來自主辦商及臺北市重大活動行事曆，部分場次來自第三方演出整理頁，請留意來源性質；並未將大巨蛋所有租借日當成演出日。
- TICC 目前僅找到並匯入一筆日期明確的 2026 年 5–9 月音樂演出。其他月份未收錄不等於沒有演出。
- 小巨蛋的資料是**空間租用紀錄**，其餘為**已公告活動**；不能以兩者直接比較出租率。
- 跨日公告區間可能不是每天演出；新匯入場次均以有證據的單日演出日期記錄。
- 週幾環形圖沿用：週一～五藍色漸層 `#237E9C`～`#4EB0CE`、週六 `#FFB64D`、週日 `#FF9E49`；圖例兩排，沒有中心數字。
